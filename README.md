# Тест скорости скачивания

Небольшой консольный скрипт на Python 3.8+ измеряет скорость загрузки ресурса по HTTP или HTTPS. Он делает 10 запросов к одному адресу строго последовательно и полностью читает тело каждого ответа.

## Запуск

Дополнительные библиотеки не нужны. В терминале перейдите в папку проекта и передайте URL ресурса:

```bash
python3 speed_test.py "https://example.com/large-image.jpg"
```

Для более крупного файла можно использовать адрес изображения или другого доступного файла. Скрипт скачивает содержимое, но не сохраняет его на диск.

По умолчанию на каждый запрос отводится не более 30 секунд. Тайм-аут можно изменить:

```bash
python3 speed_test.py "https://example.com/large-image.jpg" --timeout 60
```

## Что выводится

- время и число байтов для каждого запроса;
- среднее время запроса;
- общий объём загруженных данных;
- средняя скорость в **MB/s** и **Mbps**.

MB здесь — десятичные мегабайты (1 MB = 1 000 000 байт), Mbps — мегабиты в секунду. Итоговая скорость рассчитывается как общий объём всех ответов, делённый на сумму времени их загрузки.

Если запрос завершится HTTP-ошибкой, сетевой ошибкой или тайм-аутом, скрипт сообщит номер запроса и завершится с кодом ошибки.
